# Chart Radar — copia pubblica

Pannello in sola lettura della struttura dei grafici: azioni USA, indici e
materie prime via ETF, forex.

La pagina viene riscritta da un programma che gira su un NAS di casa. Questo
repository contiene **solo il risultato**, non il codice e nessuna credenziale.

**Le modifiche alla watchlist si fanno sul NAS**, non qui: una pagina su
GitHub Pages è un file, e un file non può ricevere comandi.

Le strutture (FVG, BoS, CHoCH, liquidity sweep, order block) sono riconosciute
da regole geometriche fisse. Il pannello descrive quello che è successo: non
prevede, non consiglia e non esegue operazioni.
